    Pertanyaan umum

    Kenapa perlu API key Google?

    Fitur cari nama usaha memakai Google Places API. Kalau pemilik situs sudah memasang key di server, Anda tidak perlu apa-apa. Kalau belum, Anda bisa memasang key sendiri lewat tombol API Key di pojok kanan atas — key disimpan di browser Anda saja, tidak dikirim ke mana pun selain ke Google lewat situs ini.

    Tanpa key pun tetap bisa: pakai tab Tempel link Google Maps.

    Apakah link ini resmi dari Google?

    Ya, formatnya search.google.com/local/writereview?placeid=… — URL milik Google yang langsung membuka kotak dialog tulis ulasan untuk usaha tersebut. Situs ini hanya membantu menyusunnya.

    Usaha saya tidak muncul di pencarian

    Pastikan profil usaha Anda sudah terdaftar dan terverifikasi di Google Bisnis Profil. Coba tambahkan nama kota/kecamatan. Kalau tetap tidak ketemu, buka Google Maps, cari usaha Anda, tekan Bagikan → Salin tautan, lalu tempel di tab kedua.

    Boleh minta ulasan ke pelanggan?

    Boleh, selama tidak memaksa atau memberi imbalan untuk ulasan positif — itu melanggar kebijakan Google dan bisa membuat ulasan dihapus. Ajak semua pelanggan memberi ulasan jujur.
